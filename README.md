# VTimer

A lightweight .NET timer application that tracks how long you’ve been sitting at your computer without interruption.

## About

VTimer helps you monitor continuous computer usage and reminds you to take breaks for better health. Built with C# and Windows Forms on .NET 10.

## Features

* Simple and intuitive interface
* Accurate tracking of active computer time
* Low system resource usage
* Quick start/stop timer

## Tech Stack

* **Language:** C#
* **Framework:** .NET 10
* **UI:** Windows Forms (WinForms)
